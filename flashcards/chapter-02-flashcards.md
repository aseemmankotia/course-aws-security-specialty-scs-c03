## Chapter 2: Incident Response: Automated Playbooks & Forensics — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What is the fastest method to isolate a compromised EC2 instance without stopping it? | Replace security groups using 'aws ec2 modify-instance-attribute --instance-id i-xxx --groups sg-isolation'. Empty security group = all traffic denied. No instance stop required, preserves memory. Exam tip: modify-instance-attribute changes SG without restart; modify-security-group-rules affects all instances using that SG. |
| 2 | SSM Run Command requirement for instances in private subnets with no internet? | VPC endpoints for: com.amazonaws.region.ssm, com.amazonaws.region.ec2messages, com.amazonaws.region.ssmmessages. SSM Agent on instance connects via these endpoints. Exam tip: SSM Agent is pre-installed on Amazon Linux 2, requires endpoints for private subnet operation. |
| 3 | Which IAM condition key blocks sessions from compromised credentials even after key deactivation fails? | aws:userid in explicit Deny policy. Deny statement with Condition: StringEquals: aws:userid: AIDAI... blocks all API calls from that IAM user regardless of access key status. Exam tip: aws:userid is user's unique ID, persists through key rotation. aws:PrincipalArn doesn't work for session revocation. |
| 4 | EventBridge rule pattern to detect S3 bucket made public via policy or ACL? | {"source":["aws.s3"],"detail-type":["AWS API Call via CloudTrail"],"detail":{"eventName":["PutBucketAcl","PutBucketPolicy"]}}. Exam tip: EventBridge patterns match CloudTrail events in near-real-time (seconds). GuardDuty S3 findings take hours/days. Config rules evaluate periodically. |
| 5 | Steps to share encrypted EBS snapshot cross-account while maintaining encryption? | 1) Create snapshot encrypted with customer-managed KMS key, 2) Modify KMS key policy: grant target account kms:CreateGrant and kms:Decrypt, 3) Share snapshot: aws ec2 modify-snapshot-attribute --snapshot-id snap-xxx --attribute createVolumePermission --operation-type add --user-ids 123456789012. Exam tip: Can't share snapshots encrypted with AWS-managed keys. |
| 6 | Difference between NACL deny rule vs Security Group removal for instance isolation? | Security Group: stateful, instance-specific, removes all traffic immediately. NACL: stateless (need explicit in+out deny), subnet-level (affects all instances), rule order matters. Exam tip: For single instance isolation use SG replacement. NACLs are defense-in-depth for subnet-level controls. |
| 7 | CloudTrail log file integrity validation: what gets hashed and how to verify? | SHA-256 hash of log file + previous hash (chain). Validation uses digest files delivered hourly to S3. Verify: aws cloudtrail validate-logs --trail-arn arn:aws:cloudtrail... --start-time <timestamp>. Exam tip: Digest files prove log files unchanged since delivery. Required for forensic chain of custody. |
| 8 | Maximum time for EventBridge to detect CloudTrail API call and trigger Lambda? | Typically 5-15 seconds. CloudTrail delivers events to EventBridge in near-real-time. Lambda cold start adds 1-3 seconds. Total incident response time: <30 seconds. Exam tip: EventBridge + Lambda is fastest automated response. Config rules can take up to 24 hours. GuardDuty findings vary (minutes to hours). |
| 9 | Memory dump command for Amazon Linux 2 via SSM Run Command? | aws ssm send-command --document-name 'AWS-RunShellScript' --parameters 'commands=["sudo dd if=/dev/mem of=/tmp/memory.dump","aws s3 cp /tmp/memory.dump s3://forensics-bucket/"]' --targets 'Key=instanceids,Values=i-xxx'. Exam tip: Requires root/sudo. Alternative tools: LiME (Linux Memory Extractor), memdump. Upload to S3 via VPC endpoint. |
| 10 | When to use 'aws iam update-access-key --status Inactive' vs 'aws iam delete-access-key'? | Inactive: During investigation, preserves key ID in CloudTrail for forensic correlation, reversible. Delete: After investigation complete, removes key permanently. Exam tip: Incident response = Inactive (evidence preservation). Routine rotation = Delete old + Create new. Inactive keys don't count toward 2-key limit. |
| 11 | AWS Security Incident Response service: what evidence does it automatically collect? | EBS snapshots of affected volumes, VPC Flow Logs for network analysis, CloudTrail logs (with digest files for integrity), S3 access logs, GuardDuty findings, Security Hub findings. Stored in isolated S3 bucket with Object Lock. Exam tip: Not included: memory dumps (manual via SSM), packet captures (requires Traffic Mirroring setup). |
| 12 | S3 bucket policy to quarantine bucket: block all access except forensics role? | {"Version":"2012-10-17","Statement":[{"Effect":"Deny","Principal":"*","Action":"s3:*","Resource":["arn:aws:s3:::bucket/*","arn:aws:s3:::bucket"],"Condition":{"StringNotEquals":{"aws:PrincipalArn":"arn:aws:iam::123456789012:role/ForensicsRole"}}}]}. Exam tip: Explicit Deny trumps all Allows. Use aws:PrincipalArn for role-based exception. Quarantine = Deny with exception, not just removing bucket policies. |
