## Chapter 8: Data Protection: Encryption at Rest, in Transit, and Data Classification — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Secrets Manager automatic rotation: What's the difference between single-user and multi-user rotation strategies? | Single-user: Updates existing user password (causes brief auth failures during rotation). Multi-user: Creates new user before disabling old one (zero downtime, both AWSCURRENT and AWSPREVIOUS work). Exam tip: Multi-user rotation = zero downtime, choose for production databases. |
| 2 | Parameter Store SecureString vs Secrets Manager: Which for configuration data that changes monthly? | Parameter Store SecureString. Reason: Config data = no automatic rotation needed, SecureString encrypts with KMS. Cost: Standard params free, Advanced $0.05/param/month. Secrets Manager = $0.40/secret/month + API calls, overkill for manual monthly changes. Exam tip: SecureString for config, Secrets Manager for auto-rotated credentials. |
| 3 | What's the cost of AWS Secrets Manager per secret per month? | $0.40 per secret per month + $0.05 per 10,000 API calls. Exam tip: If scenario doesn't need automatic rotation, Parameter Store SecureString is cheaper (free for standard, $0.05/month for advanced). Choose Secrets Manager when automatic rotation is required. |
| 4 | ACM vs ACM Private CA: When do you use Private CA? | Private CA for: Internal services, company-controlled root CA, private domains, custom certificate policies. Cost: $400/month for Private CA, unlimited cert issuance. Public ACM: Free certificates for public domains (validated via DNS/email). Exam tip: Internal microservices/VPNs = Private CA. Public websites = ACM public certs. |
| 5 | ACM Private CA: How do certificates get renewed? | Certificates issued through ACM from Private CA auto-renew before expiration (ACM managed). Certificates issued directly from Private CA via API require manual renewal. Exam tip: For auto-renewal, issue via ACM pointing to Private CA, not direct API calls to Private CA. |
| 6 | Amazon Macie: What are managed data identifiers? | Pre-built patterns detecting: credit card numbers, AWS credentials, private keys, passport numbers, SSNs, driver's licenses, bank account numbers, HIPAA/PCI DSS data types. No configuration needed. Exam tip: Use managed identifiers for standard PII, custom data identifiers for proprietary patterns (employee IDs, internal codes). |
| 7 | Macie custom data identifier: Maximum proximity value for keywords? | 300 characters. Proximity = how close regex match must be to keyword for detection. Example: regex [A-Z]{3}[0-9]{5}, keyword 'employee', proximity 50 means pattern must appear within 50 chars of 'employee'. Exam tip: Proximity increases accuracy, reduces false positives. |
| 8 | S3 encryption: What's the difference between SSE-S3, SSE-KMS, SSE-C? | SSE-S3: AWS managed keys, fully automatic, no cost. SSE-KMS: Customer managed CMK in KMS, audit logs, key rotation, pay per request. SSE-C: Customer provides keys with each request, customer manages keys outside AWS. Exam tip: SSE-S3 = default easy option. SSE-KMS = need audit trail + key control. SSE-C = regulatory requirement to manage own keys. |
| 9 | SSE-KMS: What two permissions are needed to read an encrypted S3 object? | s3:GetObject (S3 permission) AND kms:Decrypt (KMS permission). Both required. Exam tip: To restrict access even from AWS admins with S3 perms, use KMS key policy to deny kms:Decrypt for all except specific roles. Deny overrides allow. |
| 10 | S3 bucket policy condition to enforce TLS/HTTPS only? | aws:SecureTransport condition: "Deny" effect with "Condition": {"Bool": {"aws:SecureTransport": "false"}}. Blocks all non-HTTPS requests. Exam tip: SecureTransport = encryption in transit enforcement at bucket level. |
| 11 | KMS automatic key rotation: How often does it rotate? | Every 365 days (1 year). Cannot be changed or triggered on-demand. Rotates key material but keeps same CMK ID. Old material kept for decrypting existing data. Exam tip: For on-demand rotation, create new CMK and update references - not automatic rotation. |
| 12 | When Lambda calls S3/DynamoDB via VPC endpoints, is traffic encrypted? | Yes - AWS SDK uses HTTPS by default for all API calls. VPC endpoints provide private connectivity but still use TLS encryption. Traffic never leaves AWS network. Exam tip: VPC endpoints = private connectivity + encrypted by default. No need for NAT gateway for AWS service API calls. |
