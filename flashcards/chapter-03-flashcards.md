## Chapter 3: Infrastructure Security: Network Defenses & AI Guardrails — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Security groups vs NACLs: stateful or stateless? | Security groups: STATEFUL (return traffic auto-allowed). NACLs: STATELESS (must explicitly allow both inbound and outbound). Exam tip: If question mentions 'ephemeral ports' or 'return traffic rules', answer is NACL. |
| 2 | Security group evaluation: multiple rules with same port, different sources? | ALL allow rules apply - most permissive wins. No rule precedence. If sg-app allows sg-web:8080 AND 0.0.0.0/0:8080, both rules active, internet access allowed. Exam tip: Security groups NEVER deny - only allow. All allows are cumulative. |
| 3 | Network Firewall stateful rule groups: strict vs default ordering? | Strict ordering: evaluates rule groups by priority (lowest first), stops at first match. Default ordering: evaluates all rule groups, most restrictive action wins (DROP > ALERT > PASS). Exam tip: Strict = first match wins. Default = most restrictive wins. |
| 4 | AWS Network Firewall maximum throughput? | Each firewall endpoint supports up to 100 Gbps. Scale horizontally with multiple endpoints across AZs. Exam tip: If question involves >100 Gbps, answer is 'deploy multiple firewall endpoints'. |
| 5 | Shield Standard vs Shield Advanced: key difference for DDoS? | Standard: free, automatic L3/L4 protection. Advanced: $3000/month, application layer protection, health-based detection, DDoS Response Team, cost protection. Exam tip: If scenario mentions 'application layer attack' or '24/7 support', answer is Advanced. |
| 6 | WAF rate-based rule: time window for rate limiting? | 5 minutes fixed window. Count requests from single IP in 5-min period. Exam tip: Can't customize time window - always 5 minutes. If need different window, use Lambda + WAF API. |
| 7 | VPC endpoint for PrivateLink: who creates what? | Service provider creates endpoint SERVICE (with NLB). Service consumer creates endpoint INTERFACE in their VPC. Exam tip: PrivateLink = interface endpoints pointing to services in other accounts, not internet. |
| 8 | Amazon Bedrock Guardrails: denied topics vs word filters? | Denied topics: semantic matching (blocks topics like 'competitor products' even with varied phrasing). Word filters: exact/regex matching (blocks specific words like 'badword123'). Exam tip: Topic flexibility = denied topics. Precise terms = word filters. |
| 9 | Bedrock Guardrails sensitive information filters: BLOCK vs ANONYMIZE? | BLOCK: reject entire request/response if PII detected. ANONYMIZE: replace PII with placeholder (e.g., [NAME_1]). Exam tip: Compliance requirement to prevent PII = BLOCK. Need to process request but hide PII = ANONYMIZE. |
| 10 | OWASP LLM Top 10 #1: Prompt Injection - mitigation in Bedrock? | Use denied topics to block meta-instructions (e.g., 'ignore previous instructions'). Content filters don't detect prompt injection. Exam tip: Prompt injection = semantic attack, needs semantic defense (denied topics). |
| 11 | Network Firewall Suricata IPS rules: compatible format? | Suricata-compatible rules in standard Suricata format. Can import rules from open-source feeds (ET Open, etc.). Exam tip: If question asks 'can we use open-source IPS rules', answer is yes with Suricata format. |
| 12 | WAF managed rule group: AWS vs Marketplace? | AWS managed: free, maintained by AWS (Core Rule Set, Bot Control, IP Reputation). Marketplace: paid, from third parties (F5, Fortinet). Exam tip: Budget constraint + basic protection = AWS managed. Advanced/specialized = Marketplace. |
