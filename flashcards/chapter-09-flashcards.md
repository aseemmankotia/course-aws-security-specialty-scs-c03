## Chapter 9: Security Foundations: Governance, Compliance, and Multi-Account Architecture — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | SCP evaluation logic: What happens when a parent OU has Deny ec2:* and child OU has Allow ec2:*? | Deny wins - SCPs use intersection logic where all applicable SCPs must Allow an action. Deny statements cannot be overridden by Allow statements in child OUs. Exam tip: Deny always wins in SCP inheritance, no exceptions. |
| 2 | AWS Config rule evaluation timing: How quickly does Config detect non-compliant resources after creation? | Typically 10-15 minutes for configuration changes. Periodic rules can be set to 1hr, 3hr, 6hr, 12hr, or 24hr intervals. Exam tip: Config is detective control with minutes of lag, not real-time prevention. |
| 3 | CodeArtifact package origin controls: ALLOW_UPSTREAM vs ALLOW_DIRECT_PUBLISH behavior? | ALLOW_UPSTREAM: packages only from configured upstream repositories (PyPI, npm, Maven Central). ALLOW_DIRECT_PUBLISH: allows direct publishing to repository. Exam tip: Use ALLOW_UPSTREAM to enforce vetted package sources only. |
| 4 | AWS Signer signing profile types: What's the difference between Lambda and container image signing? | Lambda: AWSLambda-SHA384-ECDSA platform. Container: Notation signing with COSE format. Both provide cryptographic proof of code origin. Exam tip: Signer handles both Lambda functions and container images, different formats. |
| 5 | ECR enhanced scanning vs basic scanning: What does enhanced scanning detect that basic doesn't? | Enhanced: OS packages + language packages (npm, pip, jar, go.mod). Basic: OS packages only. Enhanced uses Amazon Inspector engine. Exam tip: Enhanced scanning = comprehensive (OS + application dependencies). |
| 6 | AWS Organizations SCP maximum limit per entity? | 5 SCPs per account or OU (including inherited). Root can have 5. Exam tip: Plan OU hierarchy carefully to avoid hitting SCP limits with inheritance. |
| 7 | Config conformance pack deployment command for organization-wide deployment? | aws configservice put-organization-conformance-pack --organization-conformance-pack-name <name> --template-s3-uri s3://bucket/template.yaml. Deploys to all accounts from management account. Exam tip: Organization feature = single deployment point. |
| 8 | Control Tower Account Factory: What does it automate for new account creation? | Automates: account creation, baseline guardrails, CloudTrail logging, Config enabling, cross-account access, SSO integration. Exam tip: Account Factory = automated secure account provisioning with guardrails. |
| 9 | AWS Config aggregator: How many source accounts can aggregate to one aggregator account? | No hard limit on source accounts. Can aggregate across organization or specific accounts. Exam tip: Use organization aggregator for automatic inclusion of all accounts, including new ones. |
| 10 | CodeArtifact external connection options: Which public repositories are supported? | PyPI (Python), npm (JavaScript), Maven Central (Java), NuGet (.NET). One external connection per repository. Exam tip: CodeArtifact proxies public repos to provide vetted, cached artifacts. |
| 11 | AWS Organizations OU design: Recommended OU structure for security isolation? | Common pattern: Security OU (logging, audit accounts), Infrastructure OU (shared services), Workloads OU (prod, dev, test), Sandbox OU (isolated experimentation). Exam tip: OU structure enables SCP inheritance for security boundaries. |
| 12 | ECR image signature verification: What service verifies signed container images before deployment? | AWS Signer creates signatures. Kubernetes admission controllers or ECR policies verify signatures before pod creation. Exam tip: Signer signs images, runtime verification happens at deployment via policies. |
