# Chapter 1 Lab: Detection: Multi-Account Threat Detection & OCSF Logging

**Estimated time:** 25 minutes

## Exercise

Enable GuardDuty in delegated admin account, aggregate findings to Security Hub, run CloudTrail Lake query to detect cross-account AssumeRole patterns, configure OCSF normalization

## Key takeaway

GuardDuty is regional and requires per-region enablement; CloudTrail Lake with OCSF normalization is the exam's preferred solution for multi-account threat hunting across heterogeneous log sources.
