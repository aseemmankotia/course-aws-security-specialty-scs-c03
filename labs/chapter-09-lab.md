# Chapter 9 Lab: Security Foundations: Governance, Compliance, and Multi-Account Architecture

**Estimated time:** 28 minutes

## Exercise

Create multi-account OU structure, attach SCP denying region outside us-east-1 and eu-west-1, deploy Config conformance pack for CIS AWS Foundations Benchmark, enable ECR enhanced scanning and verify finding aggregation to Security Hub

## Key takeaway

SCPs affect all IAM principals in member accounts EXCEPT service-linked roles and the root user; ECR enhanced scanning with Inspector integration is required for comprehensive CVE detection and Security Hub findings aggregation.
